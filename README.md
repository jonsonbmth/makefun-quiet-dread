One code-review comment that approves a pull request with quiet
existential dread, for make.fun's "Two Days of Quiet Dread" bounty.

## Run it

```sh
python3 main.py
```

Writes a single line (73 characters, no trailing newline) to
`/output/entry.txt`. Python 3.13, standard library only, no network,
no arguments. Set `OUTPUT_DIR` to write somewhere else.
